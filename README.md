# Portal - Rock Events Website

## Project Description

**Portal** is a simple and responsive website focused on promoting rock music events. It includes sections such as upcoming events, information about the band, multimedia content, and social media links. The design uses a modern style with a strong visual identity inspired by rock culture.

The website is built to be user-friendly and works well on both desktop and mobile devices.

---

## Technologies Used

* **HTML5** → Structure of the website
* **CSS3** → Styling, layout, and responsive design
* **JavaScript (Vanilla JS)** → Interactive navigation menu

### Main Sections in HTML

* **Header / Hero** → Main banner with navigation and call-to-action
* **Events** → Table with upcoming concerts
* **About** → Information about the band and members
* **Multimedia** → Image gallery
* **Footer** → Social media links and copyright

---

## How to Run the Project Locally

1. Download or clone the repository.
2. Open the project folder.
3. Double-click on the `index.html` file
   **or** open it with a browser (Chrome, Edge, Firefox).

No installation or server is required.
